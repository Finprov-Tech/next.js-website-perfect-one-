# Local Development Guide

Follow these steps to run the frontend application locally.

---

## Start the Frontend Application

In the root directory of your project:

```bash
npm run dev
```

The application will start at **`http://localhost:3000`** (or `http://localhost:5173`).

All content (courses, blogs, careers, team info) is served from static datasets inside `src/data/`.
No external CMS or API connection is required to run the site locally.
